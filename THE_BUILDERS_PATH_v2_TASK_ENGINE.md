# THE BUILDER'S PATH v2 — TASK ENGINE
## Bản điều hướng học tập từ số 0 → AI Automation & Application Builder

**Nguyên tắc:** không cần nhớ cả roadmap. Mỗi lần chỉ nhìn `CURRENT TASK`, hoàn thành nó, rồi đi đúng `NEXT`. 

## Cách dùng
1. Mở file này.
2. Tìm task đang làm.
3. Làm đúng Definition of Done.
4. Commit.
5. Chuyển thẳng tới NEXT.
6. Không tự nhảy qua task khác.

## Trạng thái
- `LOCKED`: chưa đủ prerequisite.
- `READY`: được phép làm.
- `IN_PROGRESS`: đang làm.
- `DONE`: đạt Definition of Done.
- `GAP`: chưa đạt, quay lại luyện.
